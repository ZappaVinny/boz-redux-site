Introduction

The BOZ Redux SDK is the toolkit for modding Call of Duty: Black Ops Zombies (Android 1.0.11) on PC with the BOZ Redux client. With it you can:

  • write Lua mods that change how the game plays: new rules, cheats, settings, menus, hooks into any game function;
  • build maps in the BOZ Redux editor (built on Blender): change Kino der Toten, Ascension or Call of the Dead, or make a level of your own, with your own weapons, models, sounds, effects and scripted objects;
  • read and edit the game's data files directly from the command line.

No game files come with the SDK. You need your own copy of the game, installed with the client.
