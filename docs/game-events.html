Game events

The game's systems talk to each other with events named SUBJECT_* (see How the game works). This page lists every one, with the classes that send and handle it and, where known, what its two arguments mean.

Following an event

local game_events = require("boz.game_events")

game_events.on("SUBJECT_ADD_SCORE", function(event)
    log("points earned: " .. event.a)
end)

The handler gets {name, id, subject, sender, a, b}; a and b mean what the notes say (pointers to the game's structs where noted). Returning true from a handler stops the event. Most mods never need this: the standard library already turns the common events into functions such as boz.rounds.on_start.
