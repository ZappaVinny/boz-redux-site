Made with AI assistance

BOZ Redux and its SDK were developed using human-guided generative AI. This project was made out of nostalgia for the Black Ops Zombies mobile game, I understand people may have concerns about AI-assisted development. I want to be transparent about the tools used and the human effort involved in creating this project. This project is primarily for fun and as a showcase of what AI can do. If there are more questions, join the community discords and feel free to ask!

Credits

This Project was made on the back of giants. This project would not have been possible without the cod-boz-port by Producdevity, which was the first open-source project to reverse engineer the original Black Ops Zombies mobile game. My kindest regards to Producdevity for their work!
